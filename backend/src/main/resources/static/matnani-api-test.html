🥕 맛난이 API 테스트

🔑 Token: 없음 (로그인 필요)
👤 닉네임: - | 역할: -
📦 마지막 상품ID: - | 📅 마지막 예약ID: - | 💬 마지막 댓글ID: -

1. POST /api/auth/signup — 일반 회원가입

regionId는 반드시 동(DONG) 레벨 ID 사용 (예: 1351=덕진동)

2. POST /api/auth/login — 로그인

POST /api/auth/signup/business — 사업자 회원가입

테스트 사업자번호: 0000000000

POST /api/auth/refresh — 토큰 재발급

GET /api/regions — 지역 조회

비워두면 시도, 시도ID 입력하면 구/군, 구/군ID 입력하면 동 목록

예) 6=대전 → 184=유성구 → 1351~1360=동 목록

GET /api/users/me — 내 정보

PATCH /api/users/me/region — 동네 변경

GET /api/users/{id} — 판매자 프로필

3. POST /api/products — 상품 등록 → 상품ID 자동저장됨▲ 자동입력

상품 등록 후 아래 API들에 상품ID 자동 입력됩니다



GET /api/products — 상품 목록

GET /api/products/search — 검색

GET /api/products/{id} — 상품 상세

GET /api/products/time-sale — 타임세일

PATCH /api/products/{id}/status — 상태 변경

DELETE /api/products/{id} — 상품 삭제

4. POST /api/products/{id}/reservations — 예약 → 예약ID 자동저장▲ 자동입력

5. PATCH /api/reservations/{id}/status — 상태 변경

후기 작성하려면 COMPLETED로 변경 필요

GET /api/reservations/me — 내 예약

POST /api/products/{id}/comments — 댓글 작성 → 댓글ID 자동저장▲ 자동입력

GET /api/products/{id}/comments — 댓글 조회

PATCH /api/comments/{id} — 댓글 수정

댓글 작성 후 자동입력됨

DELETE /api/comments/{id} — 댓글 삭제

6. POST /api/reservations/{id}/reviews — 후기 작성

⚠️ 예약 상태가 COMPLETED 일 때만 가능

GET /api/reviews — 전체 후기

PATCH /api/reviews/{id} — 후기 수정

DELETE /api/reviews/{id} — 후기 삭제

GET /api/notifications — 알림 목록

PATCH /api/notifications/{id}/read — 읽음

PATCH /api/notifications/read-all — 전체 읽음
